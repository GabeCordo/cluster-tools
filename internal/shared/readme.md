## Shared Library

The shared library is a common package for the _core_ and _processor_ build targets.

### Usable Packages

##### Buffers
Implementation of a **Ring Buffer** data structure.

##### Logging
Implementations for logging events.

##### NOnce
Tracking nonce values to represent transactions.

##### Socket
A standard implementation for sending data on golang sockets.

##### Terminal
A collection of ascii helper functions for terminal prints.
